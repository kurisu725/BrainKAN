# BrainKAN reproducible evaluation — 2026-10-08

This release provides the automatic workflow and records for **160 completed model fits**: two datasets, five seeds (0–4), and 16 configurations per seed. The input is a preprocessed AAL-90 FC matrix. Training fits model weights, development data determine ROI contributions and configuration choices, and the independent test cohort evaluates the final 50th-epoch model.

## Contents

- [`code/`](code/): executable BrainKAN, automatic ROI scoring/selection, training, inference, experiment runner, summary scripts and tests.
- [`results/`](results/): frozen plans, environment, exact split indices, source/data checksums, per-run class probabilities, metrics, ROI indices, contribution arrays and stability summaries.
- [`PREPROCESSING.md`](PREPROCESSING.md): reference, original passage and source location. **For the preprocessing procedure, please refer to the original article cited there (Section 4.1, p. 6).**
- `MANIFEST.sha256`: checksums of the release files.

ABIDE uses 709/89/84 training/development/test subjects; ADHD uses 679/86/82. These predefined assignments are fixed across the five seeds. Precision, recall and F1 use macro averaging; AUC uses the entire test cohort's class-1 probabilities. SD is sample SD across seeds.

## Install

The recorded experiment used Python 3.11.2, PyTorch 2.2.1+cu121, NumPy 1.26.4, SciPy 1.12.0 and scikit-learn 1.4.1.post1. See [`results/runtime.json`](results/runtime.json).

```bash
cd revision_20261008/code
python -m venv .venv
# Activate .venv for your shell, then install:
python -m pip install -r requirements.txt
```

To match the recorded CUDA 12.1 build, install `torch==2.2.1` from the PyTorch CUDA 12.1 wheel index before installing `requirements.txt`. CPU execution is also supported. The revision's requirements file uses package versions rather than the historical Windows-local wheel paths.

## Reproduce from FC data

Download all six `BrainKANDATA.part*.rar` files from the repository root and extract the multipart archive starting with part 1. Place `ALLASD1_aal.mat` and `ADHD1_aal.mat` in `code/data/`, or substitute your own file paths below. The recorded SHA256 values are in the two `results/*/plan.json` files.

From `revision_20261008/code/`:

```bash
python scripts/reviewer_experiments.py plan --dataset abide --data data/ALLASD1_aal.mat --output abide_plan.json --symmetric
python scripts/reviewer_experiments.py plan --dataset adhd --data data/ADHD1_aal.mat --output adhd_plan.json --symmetric
python scripts/reviewer_experiments.py run --plan abide_plan.json --output outputs/abide --device auto
python scripts/reviewer_experiments.py run --plan adhd_plan.json --output outputs/adhd --device auto
python scripts/reviewer_experiments.py evaluate --experiment outputs/abide --device auto
python scripts/reviewer_experiments.py evaluate --experiment outputs/adhd --device auto
python scripts/summarize_reviewer_run.py outputs
```

Generate plans with your local paths, and compare their data checksums, assignments, seeds and settings with the recorded plans before running. Recorded plans retain the original execution paths and source hashes for provenance. The `run` stage freezes development artifacts before the separate `evaluate` stage uses test labels.

Large checkpoints are regenerated by training; they are omitted from this source-and-results release. Saved metrics and probabilities can be inspected without training. The single-run `run.py` CLI also supports inference on new unlabeled FC matrices using saved ROI indices and checkpoints: `python run.py --help`.

## Inspect existing results and verify the software

```bash
# From revision_20261008/code:
python scripts/summarize_reviewer_run.py ../results
python -m unittest discover -s tests
```

Summarization writes `EXPERIMENT_REPORT.md` in the selected results directory. Machine-readable classification values for all five metrics are in each dataset's `final_test/all_runs.json` and `final_test/summary.json`. ROI stability, ranking comparisons and selected indices are included alongside the run records. This release covers the new within-BrainKAN evaluation; the earlier seven-baseline comparison is described in the manuscript.
